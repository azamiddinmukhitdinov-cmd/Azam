# Azam — Письмо для Лианночки ♡

Личное интерактивное приглашение на свидание 18 октября 2026 года. Письмо открывается после ввода даты знакомства; затем можно принять приглашение, выбрать кухню, оставить пожелания и сохранить дату в календарь.

Опубликованное приглашение: https://liannochka-secret-date.creamy-bream-2918.chatgpt.site

Репозиторий содержит исходники последней сохранённой версии сайта. Ответы гостей хранятся в Cloudflare D1, а страница `/responses` показывает их владельцу.

## Локальный запуск

Нужны Node.js 24 и pnpm 11.25.0 (версия закреплена в `package.json`).

```sh
git clone https://github.com/azamiddinmukhitdinov-cmd/Azam.git
cd Azam
pnpm install --frozen-lockfile
pnpm dev
```

Адрес локального сервера: http://localhost:5173.

```sh
# Проверка сохранения ответов, доступа владельца и валидации
node --test tests/date-preferences.test.mjs

# Сборка серверной версии
pnpm build
```

## Где менять приглашение

- `app/invitation.html` — оформление, текст, дата и взаимодействия.
- `app/responses.html` — страница ответов для владельца.
- `lib/date-preferences.ts` — сохранение и проверка ответов.
- `drizzle/` — миграции базы данных.

## Хостинг и ответы

Полная версия работает в ChatGPT Sites на Cloudflare Workers, использует D1 с привязкой `DB` и идентификацию посетителей через ChatGPT. Для просмотра ответов нужно настроить серверную переменную `OWNER_EMAIL`; образец находится в `.env.example`.

Локальный запуск позволяет проверить оформление. Сохранение ответов требует настроенной D1 и доверенных заголовков идентификации, которые предоставляет Sites. GitHub Pages обслуживает только статические файлы и не запускает этот серверный проект.

`.openai/hosting.json` сохраняет связь с существующим Sites-проектом. Изменения в GitHub сами по себе не публикуются по ссылке приглашения. Подробности сборки, локальных миграций и окружения: [docs/sites-runtime.md](docs/sites-runtime.md).
